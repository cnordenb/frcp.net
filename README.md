# frcp_html - [frcp.net](https://frcp.net/)

Fresh Random Civ Picker in the browser. Ported to HTML, CSS and JavaScript from the [C++ Windows GUI version](https://github.com/cnordenb/Fresh-Random-Civ-Picker_GUI) and using UI elements from various editions of Age of Empires 2.

New in this version of FRCP: share civ pool with URL link.
- Example, a civ pool of AoK civs: https://frcp.net/#p=1Cg4QBAgiAl8

Assets (image files for UI and civ icons, audio files for UI and civ jingles) amount to over 5mb and the site can take over a second to load. A simple 72kb version is available at [frcp.net/simple](https://frcp.net/simple) and it should load about 10x as fast.
